# Usability Tracker

### A Web-Based Human-Computer Interaction (HCI) Usability Evaluation Platform

**Usability Tracker** is a web-based HCI project designed to evaluate the usability and user experience of digital interfaces through **task-based usability testing, interaction tracking, user feedback, and usability analysis**.

## 🎯 Objectives

* Track user interactions during usability tests
* Measure task completion time, clicks, errors, and navigation
* Collect user feedback and satisfaction ratings
* Evaluate interfaces using **Nielsen's 10 Usability Heuristics**
* Calculate **System Usability Scale (SUS)** scores
* Generate usability reports and recommendations

## ✨ Key Features

* 👤 User & Test Management
* 📋 Task-Based Usability Testing
* 🖱️ Click, Scroll & Keyboard Tracking
* ⏱️ Task Completion Time Analysis
* 📊 Usability Dashboard
* ⭐ SUS Evaluation
* 🔍 Nielsen Heuristic Evaluation
* 📝 Automated Reports
* 📥 CSV/JSON Data Export

## 🔄 How It Works

```text
Create Test
     ↓
Assign Tasks
     ↓
User Performs Tasks
     ↓
Track Interactions
     ↓
Collect Feedback
     ↓
Analyze Usability
     ↓
Generate Report
```

## 📊 Usability Metrics

The system evaluates:

* Task Completion Rate
* Task Completion Time
* Click Count
* Error Count
* Navigation Activity
* User Satisfaction
* SUS Score
* Heuristic Severity
