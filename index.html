How to use

  1. Setup: add participants and tasks (a demo user, test and 3 tasks are pre-loaded).
  2. Run Test: pick user, test and task, then start the session. Clicks, scrolls, errors and time are tracked.
  3. Finish the task, then fill in the SUS questionnaire and heuristic findings.
  4. Generate a report, then export CSV/JSON from Data.
